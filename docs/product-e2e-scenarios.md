> 범위: Phase 5 제외, AI·프런트·백엔드 전체 연동 인수 기준

| ID | 시나리오 | 선행 조건 | 핵심 확인 |
| --- | --- | --- | --- |
| E2E-01 | 회원가입→로그아웃→로그인 | 프런트 인증 화면 | 토큰 저장·삭제, 로그아웃 토큰 401 |

| E2E-09 | 그룹 역할 | OWNER/MANAGER/MEMBER 계정 | 초대·역할·목표·피드백 허용/거부 |

## 실행 순서

1. 각 실행은 격리된 테스트 사용자와 세션을 생성한다.
2. API 응답, DB 결과, 화면 표시를 같은 request ID와 resource ID로 연결한다.
3. 실패 시 민감값을 제외한 요청 경로·상태·request ID를 증거로 남긴다.
4. E2E-04·05의 백엔드 fixture·HTTP 검증은 완료됐으며 AI 연결 E2E는 AI 구현 전까지 `BLOCKED`로 관리한다.
5. E2E-02·03은 AI 1분 집계 전에는 fixture API 테스트만 수행한다.
6. E2E-01·06~12의 브라우저 검증은 제품 프런트 소스가 준비된 뒤 수행한다.

## 완료 판정

- 모든 필수 시나리오가 동일 릴리스 후보에서 통과한다.
- 401·403·409·503이 정의된 UX로 표시된다.
- 점수·시간·프라이버시·역할 결과가 API와 화면에서 일치한다.
- 테스트 중 토큰, 비밀번호, DB·Redis URL이 로그와 화면에 노출되지 않는다.
