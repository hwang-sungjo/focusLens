## 2. 클라이언트 현재 상태

### 프런트엔드

- Git에 추적되는 `frontend/` 파일은 0개다.
- 로컬 `frontend/dist/` 산출물은 있지만 `package.json`과 `src/`가 없어 재현 가능한 제품 소스로 볼 수 없다.
- 제품 프런트엔드는 **구현 전**이다.

### AI

구현됨:

- Python·OpenCV·MediaPipe 웹캠 실행과 약 10 FPS 추론
- 얼굴 검출, gaze 상대 위치, 단일 프레임 눈 감김, yaw/pitch/roll 추출
- 백엔드와 같은 `total` 계산 함수
- JWT Bearer 집중도 로그 API 클라이언트
- 디버그 화면과 프레임별 JSON 출력

남음:

- 사용자별 gaze/head 보정
- blink 이벤트와 장시간 눈 감김 판정
- 1분 버퍼와 점수 집계
- 웹캠 파이프라인과 API 연결
- 실패 전송 큐와 토큰 만료 처리

AI는 Python 3.11만 지원한다. 이번 점검 환경은 Python 3.9.6이며 AI 전용 가상환경도 없어 pytest를 재실행하지 못했다. AI 연동 전 Python 3.11 환경에서 별도 검증해야 한다.

## 3. 지금 결정·준비 가능한 작업

Phase 5 작업을 제외하고, AI와 프런트 구현이 끝나기 전에도 다음 계약과 검증 기준은 정할 수 있다.

| 작업 | 상태 | 결과물 |
| --- | --- | --- |
| 로그 v2 필요 여부 결정 | ✅ | `docs/client-contract-decisions.md` |
| 장시간 세션 인증 결정 | ✅ | 회전형 Refresh Token 정책 |
| AI 재시도 기준 결정 | ✅ | 상태 코드별 처리와 backoff 규칙 |
| AI 인수 기준 작성 | ✅ | 보정·blink·미검출·1분 집계 최소 기준 |
| 프런트 API 매핑 작성 | ✅ | `docs/frontend-api-map.md` |
| 제품 E2E 시나리오 확정 | ✅ | `docs/product-e2e-scenarios.md` |

위 여섯 항목은 문서 계약으로 확정했다. 현행 v1 로그를 유지하면서 로그 v2와 Refresh Token 백엔드 구현 및 fixture·실제 HTTP 통합 검증도 완료했다.
